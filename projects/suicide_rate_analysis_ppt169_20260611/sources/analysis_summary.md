# 전세계 자살률 분석 프로젝트 (1985–2016)

**분석 목적**: GDP, HDI, 성별, 연령대 등 국가 특성이 자살률 고위험/저위험에 미치는 영향 분석
**데이터셋**: Suicide Rates Overview 1985~2016 (Kaggle) — 27,820개 레코드, 101개국, 12개 변수
**타깃 변수**: `high_risk` — 인구 10만명당 자살률 중앙값(5.99) 이상=1 / 미만=0

## 1. 탐색적 데이터 분석 (EDA) — 차트: 01_eda_overview.png

- **성별**: 남성 평균 20.7명/10만명 vs 여성 5.9명 — 남성이 약 3.5배
- **연령대**: 75세 이상 24.5명으로 최고, 5-14세 0.6명으로 최저 (연령 비례 증가)
- **연도별 추이**: 1995년경 정점(약 15.3) 이후 지속 하락, 2016년 11.4 수준
- **GDP vs 자살률**: 상관계수 +0.06 — 1인당 GDP와 자살률은 사실상 무상관 (선형관계 없음)
- 결측: HDI 69.9% 결측 → 중앙값(0.779) 대체

## 2. 전처리

- country-year 중복 컬럼 제거, gdp_for_year 문자열→숫자 변환
- sex/age/generation 원핫인코딩 (11→22 컬럼), 입력변수 18개
- 학습 22,256개 / 테스트 5,564개 (8:2 층화분할), StandardScaler 표준화

## 8. 기대효과 / 활용방안 / 리스크 및 한계

**기대효과**
- 80% 정확도의 고위험군 사전 식별 → 예방 자원 우선순위 배분 근거
- 인구통계 기반 타게팅: 고연령 남성 집중 개입 시 효율 극대화
- 군집 분석으로 국가군별 맞춤 정책 설계 가능

**활용방안**
- 국가/지자체 자살예방 정책의 우선순위 지표 수립
- 보건 예산 배분 시뮬레이션 (고위험 군집 국가 우선)
- 노인 남성 대상 조기 스크리닝 프로그램 설계 근거

**리스크 및 한계**
- 생태학적 오류: 국가 단위 집계 데이터 → 개인 예측에 직접 적용 불가
- HDI 70% 결측을 중앙값 대체 → HDI 효과 추정 왜곡 가능
- 2016년까지 데이터 — 코로나19 이후 변화 미반영
- 자살 신고/집계 기준의 국가 간 차이 (과소보고 가능성)
- 중앙값 기준 이진 분류는 임계값 설정에 민감
- 민감한 주제: 결과 해석·공개 시 윤리적 주의 필요 (낙인 효과 방지)
